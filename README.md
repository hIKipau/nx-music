# NX Music

Локальный музыкальный плеер для Nintendo Switch с Atmosphère или UltraNX. Приложение в hbmenu показывает библиотеку на SD-карте, а фоновый модуль воспроизводит музыку. Мини-оверлей открывается в игре сочетанием **+ и −** и управляет той же очередью.

## Статус версии

**0.4.6 — тестовая сборка.** В ней статическая куча модуля уменьшена с 6 до 2 МиБ. Модуль освобождает аудиовыход на паузе и после остановки, а приложение закрывает IPC-сессию при потере фокуса. Версия проетстирована на Switch oled, и работает корректно.

## Установка на SD-карту

Используйте файлы из [релиза](https://github.com/hIKipau/nx-music/releases/tag/v0.4.6) или из каталога `dist/` после [сборки из исходников](#сборка).

| Путь от корня SD-карты | Назначение |
| --- | --- |
| `switch/nx-music/nx-music.nro` | Приложение для hbmenu |
| `switch/nx-music/music/` | Папка с треками |
| `atmosphere/contents/42004E584D555349/exefs.nsp` | Фоновый модуль и мини-оверлей |
| `atmosphere/contents/42004E584D555349/flags/boot2.flag` | Флаг автозапуска фонового модуля |
| `atmosphere/contents/42004E584D555349/[nx-music].txt` | Метка папки модуля |

1. Скопируйте файлы в указанные папки. При обновлении замените и `nx-music.nro`, и `exefs.nsp`.
2. Положите музыку в `switch/nx-music/music/`.
3. Перезагрузите Switch в Atmosphère. Флаг `boot2.flag` уже включён в комплект.
4. Откройте **NX Music** в hbmenu, выберите трек и нажмите **A**.

## Управление

| Действие | Приложение | Мини-оверлей |
| --- | --- | --- |
| Открыть | Выбрать **NX Music** в hbmenu | Нажать **+ и −** одновременно |
| Запустить трек из библиотеки | **↑ / ↓**, затем **A** | — |
| Выбрать кнопку плеера | **↑** с первой строки, затем **← / →** и **A** | **← / →**, затем **A** |
| Предыдущий / следующий | **L / R** или кнопки плеера | **Previous / Next** |
| Громкость музыки | **ZL / ZR** | **ZL / ZR** |
| Обновить список и повторить подключение | **X** | — |
| Закрыть | **B** | **B** или **+ и −** |

Кнопка **A** на файле формирует очередь по списку библиотеки и начинает воспроизведение с выбранного трека. После **Stop** кнопка **Play** запускает этот трек с начала. Громкость меняется на 5 процентных пунктов и сохраняется в `config/nx-music/config.ini`. По умолчанию **ZL / ZR** управляют только громкостью NX Music. Игра может одновременно получать нажатия, сделанные в оверлее.

## Библиотека и обложки

- Форматы `.mp3`, `.flac`, `.wav` и `.wave`. Сканируются также подпапки. В списке до 300 треков. Путь к файлу должен занимать меньше 256 байт.
- Название берётся из имени файла. Сначала NX Music ищет JPEG или PNG в метаданных MP3 или FLAC, затем картинку с тем же именем, например `song.jpg` для `song.mp3`. В качестве общей обложки папки подходят `cover.png`, `cover.jpg` и `cover.jpeg`.
- Приложение поддерживает обложки до 768×768 и 8 МиБ. Мини-оверлей принимает изображения до 256×256 и 512 КиБ в пределах своего бюджета декодирования. Если подобрать обложку не удаётся, отображается нота.

## Диагностика

- Если приложение показывает ошибку подключения, проверьте наличие `exefs.nsp` и имя `boot2.flag`, затем перезагрузите консоль. **X** повторяет подключение. Для отчёта о сбое скопируйте всю строку под списком, включая код `0x…` и код после `SM`, если он отображается.
- Если файл виден, но не запускается, строка под списком показывает этап ошибки, например открытие файла, декодирование или вывод звука.
- Если зависает игра, отключите модуль, переименовав `boot2.flag` в `boot2.flag.disabled`, и перезагрузите консоль. Для сравнения запустите ту же игру. При зависании системы удерживайте **POWER** не менее 12 секунд. [Инструкция Nintendo](https://en-americas-support.nintendo.com/app/answers/detail/a_id/22744/~/how-to-power-off-the-nintendo-switch-console)
- В Ryujinx обычный запуск `nx-music.nro` проверяет интерфейс и чтение библиотеки. Фоновое воспроизведение и системный оверлей проверяются на Switch с Atmosphère. Для проверки аудиодвижка в эмуляторе использовалась отдельная тестовая сборка.

## Сборка

Понадобятся GNU Make и devkitPro с `devkitA64` с поддержкой C++26, `libnx`, `switch-tools`, `switch-pkg-config` и `switch-sdl2_ttf` с её зависимостями. Базовые пакеты для Switch входят в группу `switch-dev`. [Репозиторий пакетов devkitPro](https://github.com/devkitPro/pacman-packages)

Из корня репозитория в среде devkitPro используйте следующую команду.

```sh
make -j4 dist
```

В `dist/` появятся папки `switch/` и `atmosphere/` с файлами из таблицы установки. `make app` собирает NRO в `app/`, `make module` собирает NSP в `sys-tune/`, а `make clean` удаляет результаты сборки.

## Структура исходников

| Каталог | Код |
| --- | --- |
| [`app/`](app/) | Интерфейс hbmenu на SDL2 и SDL_ttf, библиотека и управление очередью |
| [`sys-tune/`](sys-tune/) | Воспроизведение через AudOut, декодеры, системный мини-оверлей и IPC-сервер |
| [`ipc/`](ipc/) | Команды и клиент IPC. Версия API 7, сервис `nxmusic` |
| [`common/`](common/) | Обложки, настройки, доступ к SD-карте и общие функции |

В Atmosphère приложение получает сессию через системный менеджер сервисов. Прямой именованный порт остаётся резервным путём подключения.
